LinkedIn Studio

A six-agent LinkedIn growth system that runs itself. Claude researches, writes the post, renders the carousel, emails the daily kit, and publishes once LinkedIn is connected. These files are the project; the scheduled runs restore from here when GitHub is unreachable.

Connect LinkedIn once (5 minutes)

  1. Create an app at linkedin.com/developers/apps, add the products Share on LinkedIn and Sign In with LinkedIn using OpenID Connect, and add redirect URL http://localhost:8765/callback.
  2. On your laptop: pip install -r requirements.txt, put LINKEDIN_CLIENT_ID and LINKEDIN_CLIENT_SECRET in .env, run python studio.py auth.
  3. Copy LINKEDIN_ACCESS_TOKEN and LINKEDIN_PERSON_URN from .env into the Claude Code cloud environment's secrets, and allow the domains api.linkedin.com and www.linkedin.com in its network settings.
  4. Tokens last 60 days. Re-run auth before the date in LINKEDIN_TOKEN_EXPIRES.

Comments on other people's posts, connection requests and DMs are not available through LinkedIn's API, and bots that do them get accounts restricted. The kit writes them; you click.

Run by hand

python studio.py render  content/2026-10-20.json   # JSON -> 1080x1350 PDF carousel
python studio.py brief   content/2026-10-20.json   # HTML kit
python studio.py publish content/2026-10-20.json   # post it (needs .env)
python studio.py comment urn:li:share:123 "text"   # comment as you
python studio.py metrics                           # weekly report
python test_studio.py                              # self-check
